# Data Engineering Interview Prep

An interview preparation workspace for data engineering roles, covering Python, SQL, DSA, PySpark, Kafka, Databricks, and data engineering system design.

Use the [commit message policy](docs/commit-message-policy.md) for tracked preparation and project work. Matching commits feed the [Data Engineering preparation dashboard](https://github.com/minhazalam/minhazalam#-data-engineering-preparation-dashboard).

Commit format: `de(<topic>): [<prep|project>] <short description>`.
